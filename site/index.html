cardak __VERSION__ has been released→

Your control deck for multi-project agentic development.

The video is on its way.

Get it

Needs Linux, WezTerm and uv.
The agent features need Claude Code.

Everything.

In a terminal 
# install cardak, with every extra
uv tool install 'cardak[all] @ git+https://github.com/brlauuu/cardak'
# jumping, colors, tab names and ASCII logos per project
cardak wezterm install
# Claude Code status; shows what it adds, asks first
cardak hooks install
# open the deck
cardak

Everything minus ASCII logo and AI summaries.

In a terminal 
# install cardak, without the extras
uv tool install git+https://github.com/brlauuu/cardak
# jumping, colors and tab names per project
cardak wezterm install
# Claude Code status; shows what it adds, asks first
cardak hooks install
# open the deck
cardak
In ~/.config/wezterm/wezterm.lua, before return config 
require('cardak').apply(config)
