Get it

github.com/brlauuu/cardak

Needs Linux, WezTerm and uv; the agent features need Claude Code. Developed on KDE Plasma under X11.

Everything, with each project's background art and Anthropic summaries.

uv tool install 'cardak[all] @ git+https://github.com/brlauuu/cardak'

The deck, agent status, themes, resources, the phone and PM views; summaries from a local model, Codex or an OpenAI-compatible server.

uv tool install git+https://github.com/brlauuu/cardak
Then run cardak, and:
  1. cardak wezterm install for jumping and per-project colors; add the line it prints, require('cardak').apply(config), to your wezterm.lua.
  2. cardak hooks install for Claude Code status; it shows what it will add to Claude Code's settings and asks first.
The README covers the rest.
