A project-centric deck for WezTerm panes and Claude Code sessions. cardak groups every pane by project, takes you to any of them in one keystroke, gives each project its own colors, and tells you which Claude Code session is waiting on you, and why.

What it does

  • Every pane, grouped by project All your WezTerm panes in one tree, by project. Enter jumps to the pane and raises its window.
  • A color for each project Each project gets its own color scheme, and its tabs are named after it, so you always know where you are.
  • Who is waiting on you Every Claude Code session is working, waiting or idle. Waiting ones come first, with the reason, a notification and a sound.
  • Why, in one line An optional one-line summary of what each waiting session needs, written by a model you choose, local ones included.
  • Which pane is eating your machine CPU and RAM per pane and project, Docker builds included, with alerts before memory runs out and 30 days of history.
  • What your sessions cost This month's Claude Code use at API prices, usage per project and day, each session's context, and your plan limits.
  • Pick up where you left off A checkpoint skill writes a handoff note in the project; the recap gathers notes and recent git activity.
  • Your projects' issues and PRs A board per project: open issues, the ones a branch or PR is working on, and what got done this week.
  • On your phone A read-only page on your local network shows who is waiting, while you're away from the desk.

Get it

Needs Linux, WezTerm and uv; the agent features need Claude Code. Developed on KDE Plasma under X11.

uv tool install git+https://github.com/brlauuu/cardak
cardak

Then, for jumping and per-project colors, cardak wezterm install, and for Claude Code status, cardak hooks install. Each one shows what it will change and asks first. The README covers the rest.
