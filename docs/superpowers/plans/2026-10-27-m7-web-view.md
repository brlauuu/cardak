# M7: the deck on a phone — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only, key-protected web page for phones and tablets on the home network, served by `cardak daemon` from the snapshot it already takes.

**Architecture:** A new front-end package `cardak/web/` (`cli → web → core`): `view.py` turns a `DeckSnapshot` into a whitelisted JSON view, `server.py` serves one static page and two GET endpoints with `http.server` on a background thread, `key.py` and `lan.py` back `cardak web setup|off|status`. `core/daemon.py` gains a publish callback and, with the web on, polls with agent status in a read-only "seen" mode (`LiveSource(write_seen=False)`). `cli.py` wires it.

**Tech Stack:** Python 3.13 stdlib (`http.server`, `hmac`, `secrets`, `json`), one static HTML file with inline CSS/JS, `segno` for the QR code.

**Spec:** `docs/superpowers/specs/2026-10-27-m7-web-view-design.md`

## Global Constraints

- Layering: `core` never imports `cardak.web`; `cardak.web` imports `core` (and `collectors` types only through core); `web` never imports `ui`, `wezterm`, `claude`, `llm`, `systemd`.
- Read-only: only `GET`/`HEAD` handlers; nothing in the daemon's poll or a request writes to the store (no `mark_seen`, no `update`).
- `cardak hook` imports nothing new (`test_hook_imports_only_what_it_needs` stays green); `segno` is imported only inside `cardak web setup`/`status`.
- Defaults: `[web] enabled = false`, `port = 8765`, `host = "0.0.0.0"`. Key file `~/.config/cardak/web_key`, `secrets.token_urlsafe(32)`, mode 0600; refused with group/other bits.
- Page polls every 3 s while visible; a snapshot older than 10 s is "stale".
- URL form: `http://<ip>:<port>/#k=<key>`. Data requests: `Authorization: Bearer <key>`, compared with `hmac.compare_digest`.
- Copy (exact): no key → "open the link from `cardak web setup` (or scan its QR code) on this device"; 401 → "this link's key is no longer valid · run `cardak web setup` on the computer"; unreachable → "can't reach cardak · last data from HH:MM".
- Commit subjects end with `(#80)` (the M7 issue, created in Task 0).

## Review Focus

1. A wait the user focused in WezTerm for ≥ 1 s while the deck is closed leaves "Waiting on you" on the page, and the store row is still `waiting` afterwards. Test in Task 2.
2. The daemon keeps alerting when the web can't start: port taken, key file missing or mode 0644, `[web]` invalid. One log line each. Test in Task 5.
3. A prompt or summary containing `<img src=x onerror=…>` shows as text on the page. The page never uses `innerHTML`, `outerHTML`, `insertAdjacentHTML` or `document.write`. Test in Task 6.
4. WezTerm goes away and polls start failing: the published `ts` stops advancing while `now` keeps advancing, so the page shows stale data. Before the first poll, `/api/snapshot` answers 503 `{"starting": true}`. Test in Task 4.
5. `/api/session/<id>` for an id not in the latest snapshot is 404, even if the store still has the row. The JSON never contains pids or `is_self`. Test in Tasks 3 and 4.

### Task 4: The server

**Files:**
- Create: `src/cardak/web/server.py`, `src/cardak/web/page.html` (a placeholder `<!doctype html><title>cardak</title>` until Task 6)
- Test: `tests/test_web_server.py`

**Interfaces:**
- Consumes: `snapshot_json`, `session_json` and `find_agent` (Task 3).
- Produces:
  - `class Latest`: `publish(snap: DeckSnapshot, ts: float) -> None` and `get() -> tuple[DeckSnapshot, float] | None`, both under a `threading.Lock`.
  - `make_server(host: str, port: int, key: str, latest: Latest, session: Callable[[str], SessionState | None], clock: Callable[[], float] = time.time) -> ThreadingHTTPServer`. It binds, and raises `OSError` on failure.
  - `start(server) -> threading.Thread` runs a daemon thread with `serve_forever`.
  - Routes:
    - `GET /` serves `page.html` from `importlib.resources`, with no key needed.
    - `GET /api/snapshot`: 401 without the key; 503 `{"starting": true}` before the first publish; else `snapshot_json(snap, ts, clock())`.
    - `GET /api/session/<id>`: 401 without the key; 404 when `find_agent` gives None; else `session_json(agent, session(id), clock())`.
    - `HEAD` mirrors `GET` without a body. Other paths are 404. `POST`, `PUT`, `DELETE`, `PATCH` and `OPTIONS` are 405.
    - Every response carries `Cache-Control: no-store`, `X-Content-Type-Options: nosniff` and `Referrer-Policy: no-referrer`. The page also gets `Content-Security-Policy: default-src 'none'; script-src 'sha256-…'; style-src 'sha256-…'; connect-src 'self'; img-src 'self' data:`, with the hashes computed at import from the page's inline `<script>` and `<style>` contents.
    - JSON is `application/json; charset=utf-8`.
    - `log_message` is silenced.
    - An exception inside a handler gives a 500 and one stderr line.

### Task 6: The page

**Files:**
- Modify: `src/cardak/web/page.html`, one file with one inline `<style>` and one inline `<script>`
- Test: `tests/test_web_page.py`

**Behaviour:** what the spec's "The page" section says, with mockup B as the reference.

1. **Layout**
   - Mobile first, dark.
   - The header shows `cardak`, machine `RAM used/total` with the warning level, CPU, and the freshness line.
   - Below come Waiting cards, then project cards (accent swatch, RAM, the spark string, agent dots, tap to expand panes), with Other last.
   - At `min-width: 820px`, two columns.
2. **Key**
   - On load, read `#k=` from `location.hash`. If present, store it in `localStorage["cardak-key"]` (in a try/catch) and leave the hash.
   - Else use the stored key.
   - With neither, show the no-key copy and don't poll.
3. **Polling**
   - `fetch('/api/snapshot', {headers: {Authorization: 'Bearer ' + key}, cache: 'no-store'})` every 3000 ms while `document.visibilityState === 'visible'`, plus once on `visibilitychange` to visible.
   - A 401 shows the invalid-key copy and stops polling. A 503 shows "starting…". A network error shows the unreachable copy with the last data greyed (`opacity: .5`).
   - `now - ts > 10` turns the header warning-colored, with "last update N ago".
4. **Session sheet**
   - Tapping a waiting card or an agent pane opens a sheet that fetches `/api/session/<id>` on each poll while it is open.
   - It shows what the session needs, the summary, "you asked", and this turn.
   - A 404 shows "this session has ended".
5. **Formatting**
   - Ages from the server's `now` (`12s`, `4m`, `2h`, `3d`), and GB with one decimal.
   - All text goes in through `textContent` or `createTextNode`. No `style="…"` attributes in the markup (the hash-based CSP blocks them); dynamic colors are set through `element.style`.
   - Expanded projects are kept by name across refreshes.
   - Colors: waiting `#f0a040`, working `#5fc070`, idle `#8a8f9c`; the project accent, or a neutral color when null.
