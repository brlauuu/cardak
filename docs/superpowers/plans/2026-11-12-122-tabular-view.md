# #122 Tabular main view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The deck's tree rows get aligned numeric columns, and windows at least `WIDE_AT`
columns wide get a side pane with "Waiting on you" and the machine line.

**Architecture:**
- Every row label becomes a pair, a left `Text` and a right `Text` of fixed-width columns.
  `fit_line` cuts or pads the left part to the line's width.
- `DeckApp` picks the narrow or wide mode from its width on every render and on resize:
  - **wide:** the waiting group goes to a second `Tree` (`#waiting`) in `#side`, and `w` uses a
    new `core/filter.waiting_projects`;
  - **narrow:** today's single tree, with the columns.
- Actions read the focused tree's cursor through one helper.

**Tech Stack:** Python 3.13, Textual 8.2.8 (`Tree`), Rich `Text`, pytest.

**Spec:** `docs/superpowers/specs/2026-11-12-122-tabular-view-design.md`

## Global Constraints

- Only `ui/` and `core/filter.py` change. `web/page.html` doesn't change.
- **Text, not markup:** free text (titles, reasons, cwd) only ever goes into a `Text`, never a
  markup string.
- **Widths:** measure with `Text.cell_len` / `rich.cells.cell_len`, never `len`.
- **Cutting:** the right columns are never cut. The left part is cut with `…`.
- **Values:**
  - `WIDE_AT = 120`: the app's width at or above which the side pane shows.
  - `SIDE_WIDTH = 42`.
- **Column order:** `state`, `RAM`, `CPU`, `ctx`, `month`.
- **State text:** `wait <age>`, `work`, `idle <age>`, with `age()` from `ui/widgets.py`.
- **Kept rendering:**
  - A row over a threshold keeps `OVER` on its RAM and CPU.
  - A waiting state is in the `WAITING` color.
  - The RAM graph is cyan, as today.
- **Gate:** ruff, `ruff format --check`, pyright, and pytest with `--cov-fail-under=80`. enola
  must show no new findings, or each one is accepted in AGENTS.md.

## Review Focus

1. **Wide characters:** a title with CJK or emoji. Columns still line up, measured in cells
   (Task 1 test `test_fit_line_counts_cells`).
2. **Very narrow tree:** the left part's width at or below 0. The left becomes `…` or empty, and
   the line is still exactly the columns (Task 1 `test_fit_line_when_columns_fill_the_width`).
3. **Resize across `WIDE_AT` with the cursor on a wait:** focus and cursor follow the spec's
   rules (Task 3 `test_resize_moves_between_modes_keeping_the_wait`).
4. **Nothing waiting in the wide mode:** the pane reads "Nothing waiting on you", and `w` shows
   the tree's nothing-waiting label (Task 3 `test_wide_with_nothing_waiting`).
5. **An unreachable or error snapshot in the wide mode:** the tree shows the error label, the
   pane shows nothing waiting, and nothing crashes (Task 3 `test_wide_error_snapshot`).

### Task 1: Row columns in `ui/widgets.py`

**Files:**
- Modify: `src/cardak/ui/widgets.py`: `usage`, `group_label`, `pane_label`, `mcp_label`,
  `docker_label`, `outside_label`.
- Test: `tests/test_widgets.py`.

**Interfaces:**
- Produces:
  - `Row = tuple[Text, Text]`, a left part and its columns.
  - `COLUMNS: tuple[tuple[str, int], ...]`, the headings and their cell widths, in order.
  - `COLUMNS_WIDTH: int`, the sum of the widths plus the gaps.
  - `columns(state: Text | None, rss: int | None, cpu: float | None, *, total: int | None, spark: str = "", over: bool = False, ctx: int | None = None, month: float | None = None) -> Text`.
    It returns exactly `COLUMNS_WIDTH` cells, each value right-aligned in its column. `None`
    means blank.
  - `heading() -> Text`: the column headings, dim, `COLUMNS_WIDTH` cells.
  - `fit_line(row: Row, width: int) -> Text`: the left part padded or cut with `…` to
    `width - COLUMNS_WIDTH`, then the columns. When that is ≤ 0, it returns only the columns.
  - `group_row(g, total) -> Row`, `pane_row(r, now, total) -> Row`, `mcp_row(r, total) -> Row`,
    `docker_row(line, total) -> Row` and `outside_row(g, total) -> Row` replace the `*_label`
    functions of the same kind:
    - `pane_row`'s left part keeps ▲, the dot, the label, the detail, the cwd, the current tool
      when working, and "(this deck)". `state` and `ctx` go to the columns.
    - `group_row`'s left part is the name, the "not in config" note and the path; its month is
      `g.spend_usd` when set.
  - `waiting_label`, `reason_label`, `machine_label` and the error and empty labels don't change.
  - Remove `usage` once nothing calls it; the web view has its own formatting.

    t = columns(None, 1_200 * 2**20, 30.0, total=32 * 2**30)
    assert t.cell_len == COLUMNS_WIDTH
    assert "1.2G (4%)" in t.plain and t.plain.rstrip().endswith("30%")

def test_columns_blank_where_none():
    assert columns(None, None, None, total=None).plain.strip() == ""

def test_heading_names_every_column_in_order():
    words = heading().plain.split()
    assert words == ["state", "RAM", "CPU", "ctx", "month"]
    assert heading().cell_len == COLUMNS_WIDTH

def test_fit_line_pads_and_cuts_the_left():
    row = (Text("cardak  ~/repos/cardak"), columns(None, 2**30, 1.0, total=None))
    assert fit_line(row, COLUMNS_WIDTH + 40).cell_len == COLUMNS_WIDTH + 40
    cut = fit_line(row, COLUMNS_WIDTH + 10)
    assert cut.cell_len == COLUMNS_WIDTH + 10 and cut.plain[9] == "…"

def test_fit_line_counts_cells():
    row = (Text("项目 🚀 build"), columns(None, 2**30, 1.0, total=None))
    assert fit_line(row, COLUMNS_WIDTH + 8).cell_len == COLUMNS_WIDTH + 8

def test_fit_line_when_columns_fill_the_width():
    row = (Text("x" * 50), columns(None, 2**30, 1.0, total=None))
    assert fit_line(row, COLUMNS_WIDTH - 5).plain == row[1].plain

def test_pane_row_puts_state_and_ctx_in_columns():  # agent waiting 4 min, ctx 140_000
    left, right = pane_row(waiting_row, now, total)
    assert "wait 4m" in right.plain and "140k" in right.plain
    assert "wait" not in left.plain and "RAM" not in left.plain
    # the WAITING style is on the state span; OVER on RAM/CPU for an over row

def test_group_row_month_only_when_spent():
    assert "$88" in group_row(group_with_spend(88.0), None)[1].plain
    assert "$" not in group_row(group_with_spend(None), None)[1].plain

### Task 3: Two modes in `DeckApp`

**Files:**
- Modify: `src/cardak/ui/app.py`: compose, CSS, `_leaves`, `_rebuild`, `_render`,
  `apply_snapshot`, `action_waiting_only`, the cursor helpers, every `deck_tree.cursor_node`
  reader.
- Test: `tests/test_app.py`. Existing tests run at the default size (80×24), which is narrow, so
  they keep today's behavior apart from the label text.

**Interfaces:**
- Consumes: Task 1's `Row`, `fit_line`, `heading` and `*_row`; Task 2's `waiting_projects`.
- Produces:
  - `DeckApp.wide -> bool`, true when `self.size.width >= WIDE_AT`.
  - `DeckApp.waiting_tree -> Tree[NodeData]`, the `#waiting` tree.
  - `DeckApp._cursor_node() -> TreeNode[NodeData] | None`: the cursor of `#waiting` when it has
    focus, else of the deck tree. Every action that read `self.deck_tree.cursor_node` uses it.
- Layout:
  ```
  TopBar #top
  Static #machine       (narrow only)
  Static #banner, #crash, Input #find
  Horizontal #main
    Vertical #left:  Static #heading, Tree #tree
    Vertical #side (width SIDE_WIDTH, border-left; display only when wide):
      Static "Waiting on you" (WAITING, bold), Tree #waiting, Static #side-machine
  Footer
  ```

Behavior:
- **Line width:** each tree line is `fit_line(row, width)`, where `width` is the tree's content
  width minus that node's indent.
  - Measure the indent from Textual's `Tree` (guide width × depth, with the root hidden) and pin
    it with a test that the right edges line up (below).
  - `#heading` is `fit_line((Text(), heading()), tree content width)`.
- **Wide `_rebuild`:**
  - The main tree skips the `"waiting"` group, and `_leaves` drops the `reason` lines.
  - `#waiting` gets, per waiting row, `waiting_label`'s first part as a leaf
    `Node(group, row, "pane")`, and the reason as a leaf `Node(group, row, "reason")`. Both are
    cut to the pane's width.
  - With no waits, it gets one data-less leaf, "Nothing waiting on you" (dim).
  - `#side-machine` gets `machine_label`, wrapped.
- **`w` while wide:** `waiting_projects` replaces `waiting_only`, and an empty result shows
  `nothing_waiting_label()`.
- **Narrow:** today's `_rebuild`, with the `*_row` lines fitted. Waiting rows use `waiting_label`
  cut to the line width.
- **Resize:** `on_resize` calls `self._render(follow_best=False)` when `wide` changed or the
  width changed. A rebuild on every resize is fine at about 30 rows.
- **Mode switch:**
  - Narrow to wide: focus stays on `#tree`, and `_where_it_was` already maps `w:`/`r:` to `p:`.
  - Wide to narrow with `#waiting` focused: remember the pane's selected id, mapping an `r:N`
    from the pane to `w:N`. Restore it in the tree and focus the tree.
- **Keys:**
  - `Binding("tab", "focus_next")` and `Binding("shift+tab", "focus_previous")` cycle `#tree`
    and `#waiting` only. `#find` keeps its own focus path, and the hidden input is skipped.
  - j/k, ←/→ and Enter act on the focused tree.
  - Enter on `#waiting` jumps, through the existing `Tree.NodeSelected` handler, which already
    handles a row.
