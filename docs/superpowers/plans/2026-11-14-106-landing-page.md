# #106 Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign `site/index.html` (tagline, video + install row, a seven-slide carousel of generated screenshots) and close #106's follow-ups.

**Architecture:** The page stays static HTML/CSS with a small inline script. A new `scripts/make_screens.py` drives the real deck headless on invented data and the real phone page in headless Chrome, and commits PNGs to `site/assets/screens/`. The daemon gains two unauthenticated icon routes for the phone page.

**Tech Stack:** HTML/CSS/vanilla JS, Python 3.13, Textual 8.2.8 (`run_test`, `export_screenshot`), headless Chrome, pytest.

**Spec:** `docs/superpowers/specs/2026-11-14-106-landing-page-design.md`

## Global Constraints

- Tagline, exact: "Your control deck for multi-project agentic development."
- Full: `uv tool install 'cardak[all] @ git+https://github.com/brlauuu/cardak'`; Lite: `uv tool install git+https://github.com/brlauuu/cardak`.
- `site/index.html`: relative paths only, nothing loaded from elsewhere, no `<script src>`, `__VERSION__` kept in the footer, no `eval`.
- Brand colors only: `#0f2a44`, `#c8352b`, `#f6efe2` (graphite `#17181c` only in the one-ink mark).
- Screenshots: invented data only; never read `~/.config`, `~/.claude`, `~/.cache` or real state (XDG dirs pointed at a scratch dir). Deck's default look, ~160×40, PNG at 2×, each aim < 300 KB.
- Carousel: no autoplay; works without JS as a scrollable strip.
- `site/assets/cardak-mark-light.svg` is **kept** (the owner's site uses it).
- `og:url` = `https://brlauuu.dev/cardak/`; `og:image` = `https://brlauuu.dev/cardak/assets/cardak-og.png`, 1200×630.
- Commits end with the two attribution lines (Co-Authored-By, Claude-Session).

## Review Focus

- **390 px phone:** no horizontal page scroll, the long Full command copyable (copy button) → test asserts each `<pre>` command has a `button[data-copy]` sibling; live check at 390×844.
- **No JS / clipboard blocked:** the strip still scrolls; copy falls back to selecting the text → JS handles a rejected `navigator.clipboard.writeText` by selecting the `<code>`; checked in the live check with JS disabled.
- **Leaking the machine into public images:** an SVG containing `/home/`, the user's name or a real repo → test in Task 4 asserts the generated SVG text has no `os.path.expanduser("~")`, no `getpass.getuser()` and only invented project names.
- **Phone icon routes taking auth or the key:** a request for the icon must work without `Authorization` and never 401, and unknown paths still 404 → tests in Task 1.
- **Keyboard and dots out of sync after a swipe:** dots follow scroll position (IntersectionObserver or `scroll` handler), not only button clicks → live check: swipe, then press →.

### Task 4: Generated screenshots

**Files:**
- Create: `scripts/make_screens.py`, `site/assets/screens/{overview,waiting,summaries,usage,board,colors,phone}.png`
- Test: `tests/test_make_screens.py`

**Interfaces:**
- `demo_snapshot(now: float) -> DeckSnapshot` — invented: 6–8 projects under `/home/demo/code/<name>` (names like `webshop`, `api-gateway`, `docs-site`, `ml-pipeline`, `mobile-app`, `infra`), ~14 panes, agents in working / waiting (2–3, with reasons and summaries) / idle, RAM/CPU history, context, month spend, plan limits, Other.
- `deck_svgs(out: Path, size: tuple[int, int] = (160, 40)) -> dict[str, Path]` — runs `DeckApp` headless per slide (`run_test(size=…)`, stub source and stub `pm`, `log`, `load_schemes`, `summaries` as in `tests/test_app.py` / `test_pm_screen.py` / `test_history_screen.py`), presses keys to reach each screen, writes `<slide>.svg` with `app.export_screenshot()`; keys: overview none; waiting `tab` then `i` (or the side pane focused, whichever reads better); summaries the waiting pane with summaries on; usage `h` then `c` to a cost figure; board `P`; colors `t`.
- `phone_png(out: Path) -> Path` — the real `make_server` on `127.0.0.1:0` with a `Latest` holding `demo_snapshot`, headless Chrome `--window-size=390,844 --force-device-scale-factor=2` on `http://127.0.0.1:<port>/#k=<key>`, `--virtual-time-budget` long enough for the first poll; then composed (or framed) into a landscape slide `phone.png`; the portrait shot is also kept as `phone-portrait.png` for narrow screens.
- `to_png(chrome: str, svg: Path, png: Path) -> None` — Chrome screenshot of the SVG at 2×, cropped to the SVG's size.
- `main()` — scratch XDG dirs set **before** importing cardak (`XDG_CONFIG_HOME`, `XDG_STATE_HOME`, `XDG_CACHE_HOME`, `CARDAK_CONFIG`), writes the seven PNGs.
