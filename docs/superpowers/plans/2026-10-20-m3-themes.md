# M3 Themes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each project gets a WezTerm color scheme that its windows switch to automatically. The deck has a theme picker with live preview, group accents come from schemes, and an opt-in zsh hook tints panes by project.

**Architecture:**
- The static `cardak.lua` (module v2) loads a generated `cardak_projects.lua` and re-themes windows on `update-status`. A `cardak_preview` user var previews a scheme per project path.
- `wezterm/generate.py` renders the data files, and `wezterm/schemes.py` lists built-in schemes through a headless probe.
- `core/config.py` edits `projects.toml` in place with tomlkit.
- `core/themes.py` derives accents and tints.
- `LiveSource` regenerates the files on every config change.
- `ui/theme_picker.py` is the picker.

**Tech Stack:** Python ≥3.12, Textual 8 (`OptionList`, `textual.fuzzy.Matcher`), tomlkit (new runtime dependency), WezTerm 20240203 Lua API, zsh.

**Spec:** `docs/superpowers/specs/2026-10-20-m3-themes-design.md`

## Global Constraints

- Layering: `cli → {ui, wezterm} → core → collectors`.
  - `ui` never imports `cardak.wezterm`; a failed scheme load arrives as any `Exception` from the injected loader.
  - `core` never imports `ui` or `cardak.wezterm`.
- **Files cardak writes:**
  - every one is written atomically into the symlink's target, keeping an existing file's mode (default 0644);
  - a file whose first line lacks cardak's marker (`-- cardak: generated` for Lua, `# cardak: generated` for zsh and tints) is never overwritten, except by a CLI command given `--force`;
  - generated files are written only when their content changes.
- cardak never reads or edits `wezterm.lua` or `.zshrc`.
- Text shown via `notify`, `Label` or `Static.update` passes through `textual.markup.escape`.
- **CI:** `ruff check`, `ruff format --check`, `pyright`, `pytest --cov=cardak --cov-branch --cov-fail-under=80`.
- **Git workflow:**
  - work on branch `8-themes`; `main` is protected, so changes land through a PR with a green `test` check;
  - commit subjects are conventional and end in `(#8)`, with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - imports shown above a test snippet go into the file's top import block;
  - splitting a long string literal to satisfy E501 is not a deviation.
- Run everything with `uv run`.
- Never touch the user's real `~/.config/wezterm`, `~/.config/cardak` or `~/.cache/cardak` in tests or the live check. Use `tmp_path`, or a scratch `XDG_CONFIG_HOME` / `XDG_CACHE_HOME`.

## Spec refinements made while planning

- The picker doesn't preview the project's current scheme when it opens (it is already on screen); it previews it only after another scheme was previewed, to undo that preview.
- `project_tint(project, schemes)` drops the spec's `default_scheme` parameter. A project with no `theme` and no `tint` gets no tint, so non-project directories reset to the scheme background.
- `tint.zsh` re-reads `tints` on every `cd` instead of tracking its mtime. The file is a few lines, and this also picks up changes immediately.
- The resolver's `Resolved` and the snapshot's `Group` gain `theme: str | None = None`, so the picker can mark the current scheme.
- An old (v1) `cardak.lua` shows in the deck's banner as a warning for as long as it stays installed, rather than once per run.

## Review Focus

1. **A scheme name containing Lua-significant characters** (`]]`, quotes, a backslash, e.g. `Belafonte Day` is fine but a hand-typed `x]]y` is not): the generated `cardak_projects.lua` must still be valid Lua. Test in Task 4 (`test_lua_strings_survive_closing_brackets`).
2. **projects.toml with comments, odd spacing and a trailing comment on the `theme` line:** saving a theme changes only that value. Test in Task 1 (`test_set_project_theme_keeps_comments_and_layout`).
3. **Scrolling quickly through the picker:** only the scheme you stop on is previewed (one write per pause, not per row). Test in Task 8 (`test_preview_is_debounced`).
4. **Closing the picker with Esc after previewing:** the preview is cleared, so the window returns to its saved scheme. Test in Task 8 (`test_escape_clears_preview_and_saves_nothing`).
5. **Every probe failure mode** (missing wezterm, timeout, no output file, garbage JSON, a scheme with non-hex colors): no crash, and a reason is shown. Tests in Task 3 (`test_probe_failures`, `test_invalid_schemes_are_skipped`).

```python
def set_project_theme(path: Path, project_path: Path, theme: str) -> None:
    """Set one project's `theme` in place; comments and layout elsewhere are kept."""
    load(path)  # refuses a broken file before anything is written
    target = path.resolve()
    doc = tomlkit.parse(_read(target) or "")
    projects = doc.get("project")
    if projects is not None and not isinstance(projects, AoT):
        raise ConfigError(path, "projects are not written as [[project]] tables; edit it by hand")
    project_path = project_path.expanduser()
    for table in projects or []:
        raw = table.get("path")
        if isinstance(raw, str) and Path(raw).expanduser() == project_path:
            table["theme"] = theme
            break
    else:
        raise ConfigError(path, f"{project_path} is not a configured project")
    text = tomlkit.dumps(doc)
    _parse(path, text)
    _atomic_write(path, target, text)
```

```python
"""Accent and tint colors derived from a WezTerm color scheme. Pure, except SchemeStore."""

from collections.abc import Mapping
from dataclasses import dataclass

from cardak.core.config import Project

MIN_CONTRAST = 1.5


@dataclass(frozen=True)
class Scheme:
    name: str
    background: str
    foreground: str
    cursor_bg: str | None
    ansi: tuple[str, ...]


def _rgb(color: str) -> tuple[int, int, int]:
    h = color.lstrip("#")
    return int(h[0:2], 16), int(h[2:4], 16), int(h[4:6], 16)


def _luminance(color: str) -> float:
    def channel(c: int) -> float:
        v = c / 255
        return v / 12.92 if v <= 0.03928 else ((v + 0.055) / 1.055) ** 2.4

    r, g, b = (channel(c) for c in _rgb(color))
    return 0.2126 * r + 0.7152 * g + 0.0722 * b


def contrast(a: str, b: str) -> float:
    """WCAG contrast ratio, 1.0 (same) to 21.0 (black on white)."""
    la, lb = _luminance(a), _luminance(b)
    return (max(la, lb) + 0.05) / (min(la, lb) + 0.05)


def default_accent(s: Scheme) -> str:
    c = s.cursor_bg
    if c and contrast(c, s.background) >= MIN_CONTRAST and contrast(c, s.foreground) >= MIN_CONTRAST:
        return c
    return s.ansi[5] if len(s.ansi) > 5 else s.foreground


def tint(background: str, accent: str, amount: float = 0.10) -> str:
    mixed = (
        round(b + (a - b) * amount) for b, a in zip(_rgb(background), _rgb(accent), strict=True)
    )
    return "#" + "".join(f"{c:02x}" for c in mixed)


def project_accent(project: Project, schemes: Mapping[str, Scheme]) -> str | None:
    if project.accent:
        return project.accent
    scheme = schemes.get(project.theme) if project.theme else None
    return default_accent(scheme) if scheme else None


def project_tint(project: Project, schemes: Mapping[str, Scheme]) -> str | None:
    if project.tint:
        return project.tint
    scheme = schemes.get(project.theme) if project.theme else None
    if scheme is None:
        return None
    return tint(scheme.background, project_accent(project, schemes) or default_accent(scheme))


class SchemeStore:
    """The scheme list shared by the deck and its source; replaced whole, never mutated."""

    def __init__(self, schemes: Mapping[str, Scheme] | None = None) -> None:
        self._schemes: Mapping[str, Scheme] = dict(schemes or {})

    def get(self) -> Mapping[str, Scheme]:
        return self._schemes

    def set(self, schemes: Mapping[str, Scheme]) -> None:
        self._schemes = dict(schemes)
```

```python
class FakeWezterm:
    """Answers `wezterm --version` and the probe; writes the probe output like real wezterm."""

    def __init__(self, output: object = RAW, version: str = "wezterm 20240203-110809-5046fc22",
                 exc: Exception | None = None, write: bool = True) -> None:
        self.output, self.version, self.exc, self.write = output, version, exc, write
        self.calls: list[Sequence[str]] = []

    def __call__(self, cmd: Sequence[str], **kwargs: object) -> subprocess.CompletedProcess[str]:
        self.calls.append(cmd)
        if self.exc:
            raise self.exc
        if list(cmd) == ["wezterm", "--version"]:
            return subprocess.CompletedProcess(cmd, 0, self.version + "\n", "")
        env = kwargs["env"]
        assert isinstance(env, dict)
        if self.write:
            text = self.output if isinstance(self.output, str) else json.dumps(self.output)
            Path(env["CARDAK_SCHEMES_OUT"]).write_text(text)
        return subprocess.CompletedProcess(cmd, 0, "", "")
```

```python
HEX = re.compile(r"^#[0-9a-fA-F]{6}$")

PROBE = """local wezterm = require 'wezterm'
local out = {}
for name, c in pairs(wezterm.color.get_builtin_schemes()) do
  out[name] = { background = c.background, foreground = c.foreground,
                cursor_bg = c.cursor_bg, ansi = c.ansi }
end
local f = assert(io.open(os.getenv('CARDAK_SCHEMES_OUT'), 'w'))
f:write(wezterm.json_encode(out))
f:close()
return {}
"""


class SchemesUnavailable(Exception):
    pass


def default_cache_dir(env: Mapping[str, str] | None = None) -> Path:
    env = os.environ if env is None else env
    if env.get("XDG_CACHE_HOME"):
        return Path(env["XDG_CACHE_HOME"]) / "cardak"
    return Path(env.get("HOME") or Path.home()) / ".cache" / "cardak"


def _hex(value: object) -> str | None:
    return value if isinstance(value, str) and HEX.match(value) else None


def parse_schemes(data: object) -> dict[str, Scheme]:
    if not isinstance(data, dict):
        raise SchemesUnavailable("unexpected probe output")
    schemes: dict[str, Scheme] = {}
    for name, c in sorted(data.items()):
        if not isinstance(name, str) or not isinstance(c, dict):
            continue
        background, foreground = _hex(c.get("background")), _hex(c.get("foreground"))
        ansi = c.get("ansi")
        if background is None or foreground is None or not isinstance(ansi, list):
            continue
        ansi_hex = tuple(a for a in ansi if _hex(a))
        if len(ansi_hex) != len(ansi):
            continue
        schemes[name] = Scheme(name, background, foreground, _hex(c.get("cursor_bg")), ansi_hex)
    return schemes


def _version(runner: Runner) -> str:
    try:
        out = runner(["wezterm", "--version"], capture_output=True, text=True, timeout=5)
    except FileNotFoundError:
        raise SchemesUnavailable("wezterm is not installed") from None
    except subprocess.TimeoutExpired:
        raise SchemesUnavailable("wezterm --version timed out") from None
    words = out.stdout.split()
    return re.sub(r"[^A-Za-z0-9._-]", "_", words[-1]) if words else "unknown"


def _cache_file(cache_dir: Path, runner: Runner) -> Path:
    return cache_dir / f"schemes-{_version(runner)}.json"


def read_cached_schemes(cache_dir: Path, runner: Runner = subprocess.run) -> dict[str, Scheme] | None:
    """The cached list for the installed WezTerm, without ever running the probe."""
    try:
        return parse_schemes(json.loads(_cache_file(cache_dir, runner).read_text()))
    except (OSError, ValueError, SchemesUnavailable):
        return None


def _probe(runner: Runner) -> object:
    with tempfile.TemporaryDirectory(prefix="cardak-schemes-") as tmp:
        probe, out = Path(tmp) / "probe.lua", Path(tmp) / "schemes.json"
        probe.write_text(PROBE)
        try:
            done = runner(
                ["wezterm", "--config-file", str(probe), "ls-fonts", "--list-system"],
                capture_output=True,
                text=True,
                timeout=20,
                env={**os.environ, "CARDAK_SCHEMES_OUT": str(out)},
            )
        except FileNotFoundError:
            raise SchemesUnavailable("wezterm is not installed") from None
        except subprocess.TimeoutExpired:
            raise SchemesUnavailable("wezterm timed out listing schemes") from None
        try:
            raw = out.read_text()
        except OSError:
            raise SchemesUnavailable(
                f"wezterm did not write the scheme list (exit {done.returncode})"
            ) from None
    try:
        return json.loads(raw)
    except ValueError:
        raise SchemesUnavailable("unexpected probe output") from None


def load_schemes(cache_dir: Path, runner: Runner = subprocess.run) -> dict[str, Scheme]:
    cache = _cache_file(cache_dir, runner)
    try:
        return parse_schemes(json.loads(cache.read_text()))
    except (OSError, ValueError, SchemesUnavailable):
        pass
    data = _probe(runner)
    schemes = parse_schemes(data)
    if not schemes:
        raise SchemesUnavailable("wezterm returned no schemes")
    try:  # the cache is an optimisation; failing to write it is not an error
        cache_dir.mkdir(parents=True, exist_ok=True)
        fd, tmp = tempfile.mkstemp(dir=cache_dir, prefix=".schemes.", suffix=".json")
        with os.fdopen(fd, "w") as f:
            json.dump(data, f)
        os.replace(tmp, cache)
    except OSError:
        pass
    return schemes
```

```python
"""Atomic writes for every file cardak owns."""

import os
import tempfile
from pathlib import Path


def write_atomic(target: Path, text: str) -> None:
    """Replace target with text via a temp file beside it; keep its mode (new files: 0644).

    Callers pass the resolved path, so a symlink's target is written, not the link replaced.
    Raises OSError.
    """
    target.parent.mkdir(parents=True, exist_ok=True)
    mode = target.stat().st_mode & 0o777 if target.exists() else 0o644
    fd, tmp = tempfile.mkstemp(dir=target.parent, prefix=f".{target.name}.")
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as f:
            f.write(text)
        os.chmod(tmp, mode)
        os.replace(tmp, target)
    except BaseException:
        Path(tmp).unlink(missing_ok=True)
        raise
```

```python
"""Generate the files cardak's WezTerm module and zsh hook read, from projects.toml."""

import re
from collections.abc import Collection, Mapping
from dataclasses import dataclass
from importlib.resources import files
from pathlib import Path

from cardak.core.config import Config
from cardak.core.themes import Scheme, project_tint
from cardak.wezterm.files import write_atomic
from cardak.wezterm.install import MARKER

MODULE_VERSION = 2
ZSH_MARKER = "# cardak: generated"
PROJECTS_FILE = "cardak_projects.lua"
TINTS_FILE = "tints"
HOOK_FILE = "tint.zsh"
NO_MODULE_MSG = (
    "Themes need cardak's WezTerm module: run `cardak wezterm install` "
    "and add the line it prints to wezterm.lua."
)
OLD_MODULE_MSG = "Your cardak.lua is from an older cardak; run `cardak wezterm install` to enable themes."


class GenerateError(Exception):
    pass


@dataclass(frozen=True)
class GenerateResult:
    written: tuple[Path, ...]
    problems: tuple[str, ...]
    module_version: int | None


def lua_str(s: str) -> str:
    """A Lua long-bracket string: no escaping, whatever quotes or backslashes s holds."""
    level = 0
    while f"]{'=' * level}]" in s:
        level += 1
    eq = "=" * level
    return f"[{eq}[{s}]{eq}]"


def module_version(lua_file: Path) -> int | None:
    """Version of an installed cardak.lua: None if absent or not cardak's, 1 before M3."""
    try:
        head = lua_file.read_text(encoding="utf-8").splitlines()[:3]
    except (OSError, UnicodeDecodeError):
        return None
    if not head or not head[0].startswith(MARKER):
        return None
    for line in head[1:]:
        if m := re.fullmatch(r"-- cardak-module: (\d+)", line):
            return int(m.group(1))
    return 1


def render_projects_lua(config: Config, known: Collection[str] | None) -> tuple[str, list[str]]:
    problems: list[str] = []
    lines = [f"{MARKER} by cardak from projects.toml; edits are overwritten.", "return {"]
    default = config.defaults.get("theme")
    if isinstance(default, str):
        if known is not None and default not in known:
            problems.append(f'unknown scheme "{default}" in [defaults]')
        else:
            lines.append(f"  default = {lua_str(default)},")
    lines.append("  projects = {")
    for p in config.projects:
        if p.theme is None:
            continue
        if known is not None and p.theme not in known:
            problems.append(f'unknown scheme "{p.theme}" for {p.name}')
            continue
        lines.append(f"    {{ path = {lua_str(str(p.path))}, scheme = {lua_str(p.theme)} }},")
    lines += ["  },", "}"]
    return "\n".join(lines) + "\n", problems


def render_tints(config: Config, schemes: Mapping[str, Scheme]) -> str:
    lines = [f"{ZSH_MARKER} from projects.toml; edits are overwritten."]
    for p in config.projects:
        if color := project_tint(p, schemes):
            lines.append(f"{p.path}\t{color}")
    return "\n".join(lines) + "\n"


def _write_if_changed(path: Path, text: str, marker: str, force: bool = False) -> bool:
    target = path.resolve()
    try:
        old: str | None = target.read_text(encoding="utf-8")
    except FileNotFoundError:
        old = None
    except (OSError, UnicodeDecodeError) as e:
        raise GenerateError(f"cannot read {path}: {e}") from e
    if old == text:
        return False
    if old is not None and not old.startswith(marker) and not force:
        raise GenerateError(f"{path} was not written by cardak; not replacing it (use --force)")
    try:
        write_atomic(target, text)
    except OSError as e:
        raise GenerateError(f"cannot write {path}: {e}") from e
    return True


def write_generated(
    wezterm_dir: Path, cardak_dir: Path, config: Config, schemes: Mapping[str, Scheme] | None
) -> GenerateResult:
    written: list[Path] = []
    problems: list[str] = []
    version = module_version(wezterm_dir / "cardak.lua")
    jobs: list[tuple[Path, str, str]] = []
    if version is not None:
        text, found = render_projects_lua(config, set(schemes) if schemes else None)
        problems += found
        jobs.append((wezterm_dir / PROJECTS_FILE, text, MARKER))
    jobs.append((cardak_dir / TINTS_FILE, render_tints(config, schemes or {}), ZSH_MARKER))
    for path, text, marker in jobs:
        try:
            if _write_if_changed(path, text, marker):
                written.append(path)
        except GenerateError as e:
            problems.append(str(e))
    return GenerateResult(tuple(written), tuple(problems), version)


def install_tint_hook(cardak_dir: Path, force: bool = False) -> Path:
    path = cardak_dir / HOOK_FILE
    text = files("cardak.wezterm").joinpath(HOOK_FILE).read_text(encoding="utf-8")
    _write_if_changed(path, text, ZSH_MARKER, force=force)
    return path
```

```lua
-- cardak: generated by `cardak wezterm install`; reinstalling overwrites this file.
-- cardak-module: 2
-- Load it from wezterm.lua:  require('cardak').apply(config)
local wezterm = require 'wezterm'

local M = {}

-- Project -> scheme table that cardak writes next to this file (`cardak themes apply`,
-- or the deck whenever projects.toml changes). WezTerm reloads when it changes.
local ok, data = pcall(require, 'cardak_projects')
if not ok or type(data) ~= 'table' then data = {} end
local projects = data.projects or {}
table.sort(projects, function(a, b) return #a.path > #b.path end) -- longest prefix wins

local previews = {} -- project path -> scheme previewed from the deck's picker

local function focus_target(id)
  local pane = wezterm.mux.get_pane(id)
  if not pane then return end
  local tab = pane:tab()
  if not tab then return end
  local win = tab:window()
  if not win then return end
  tab:activate()
  pane:activate()
  local gui = win:gui_window()
  if gui then gui:focus() end
end

local function cwd_path(pane)
  local cwd = pane:get_current_working_dir()
  if not cwd then return nil end
  if type(cwd) == 'userdata' then return cwd.file_path end -- Url object (20230712+)
  return (tostring(cwd):gsub('^file://[^/]*', ''))
end

local function project_for(path)
  for _, p in ipairs(projects) do
    if path == p.path or path:sub(1, #p.path + 1) == p.path .. '/' then return p end
  end
  return nil
end

local function scheme_for(pane)
  local path = cwd_path(pane)
  local project = path and project_for(path)
  if project then return previews[project.path] or project.scheme end
  return data.default
end

local function sync(window)
  local pane = window:active_pane()
  if not pane then return end
  local scheme = scheme_for(pane)
  local overrides = window:get_config_overrides() or {}
  if overrides.color_scheme ~= scheme then
    overrides.color_scheme = scheme
    window:set_config_overrides(overrides)
  end
end

local function sync_all()
  for _, w in ipairs(wezterm.gui.gui_windows()) do pcall(sync, w) end
end

-- cardak_focus=<pane_id>:<nonce> raises a pane's window (M2).
-- cardak_preview={"path": …, "scheme": …, "n": …} previews (or, with "", clears) a scheme.
-- Both are set by the deck on its own pane; the nonce makes every request a change.
local function on_user_var(_, _, name, value)
  if name == 'cardak_focus' then
```

```python
"""Pick a color scheme for a project, previewing it live on the project's windows."""

from collections.abc import Callable, Mapping
from pathlib import Path
from typing import Protocol

from rich.text import Text
from textual import on
from textual.app import ComposeResult
from textual.binding import Binding
from textual.containers import Vertical
from textual.fuzzy import Matcher
from textual.markup import escape
from textual.screen import ModalScreen
from textual.timer import Timer
from textual.widgets import Input, Label, OptionList, Static
from textual.widgets.option_list import Option

from cardak.core.themes import Scheme

SchemeLoader = Callable[[], Mapping[str, Scheme]]


class ThemePreviewer(Protocol):
    def preview(self, project_path: Path, scheme: str) -> bool: ...


def swatch_label(scheme: Scheme, current: bool) -> Text:
    text = Text()
    text.append("██", style=scheme.background)
    text.append(" ")
    text.append("██", style=scheme.foreground)
    text.append(f" {scheme.name}")
    if current:
        text.append(" •", style="bold")
    return text


class ThemePickerScreen(ModalScreen[str | None]):
    DEBOUNCE = 0.15
    BINDINGS = [
        Binding("escape", "cancel", "Cancel"),
        Binding("down", "move(1)", show=False),
        Binding("up", "move(-1)", show=False),
    ]
    DEFAULT_CSS = """
    ThemePickerScreen { align: center middle; }
    #picker { width: 70; height: 24; border: round $accent; background: $surface; padding: 0 1; }
    #schemes { height: 1fr; }
    """

    def __init__(
        self,
        project_name: str,
        project_path: Path,
        current: str | None,
        load: SchemeLoader,
        previewer: ThemePreviewer | None,
    ) -> None:
        super().__init__()
        self._name = project_name
        self._path = project_path
        self._current = current
        self._load = load
        self._previewer = previewer
        self._schemes: Mapping[str, Scheme] = {}
        self._timer: Timer | None = None
        self._previewed = False

    def compose(self) -> ComposeResult:
        with Vertical(id="picker"):
            yield Label(f"Theme for {escape(self._name)}")
            yield Input(placeholder="filter schemes", id="scheme-find")
            yield Static("loading schemes…", id="picker-status")
            yield OptionList(id="schemes")

    def on_mount(self) -> None:
        self.query_one(Input).focus()
        self.run_worker(self._load_worker, thread=True, exit_on_error=False)

    def _load_worker(self) -> None:
        try:
            schemes = self._load()
        except Exception as e:  # the loader belongs to cli; any failure is just a message here
            self.app.call_from_thread(self._failed, str(e))
            return
        self.app.call_from_thread(self._loaded, schemes)

    def _loaded(self, schemes: Mapping[str, Scheme]) -> None:
        self._schemes = schemes
        self.query_one("#picker-status", Static).display = False
        self._refill()

    def _failed(self, reason: str) -> None:
        self.query_one("#picker-status", Static).update(
            escape(f"Couldn't list schemes: {reason}. Type an exact name and press Enter.")
        )

    def _refill(self) -> None:
        query = self.query_one(Input).value.strip()
        names = sorted(self._schemes)
        if query:
            matcher = Matcher(query)
            names = [n for n in names if matcher.match(n) > 0]
        options = self.query_one(OptionList)
        options.clear_options()
        options.add_options(
            Option(swatch_label(self._schemes[n], n == self._current), id=n) for n in names
        )
        if names:
            options.highlighted = names.index(self._current) if self._current in names else 0

    @on(Input.Changed, "#scheme-find")
    def _filter(self) -> None:
        self._refill()

    def action_move(self, step: int) -> None:
        options = self.query_one(OptionList)
        if step > 0:
            options.action_cursor_down()
        else:
            options.action_cursor_up()

    @on(OptionList.OptionHighlighted)
    def _highlighted(self, event: OptionList.OptionHighlighted) -> None:
        if self._timer is not None:
            self._timer.stop()
        name = event.option.id
        # The current scheme is already on screen; preview it only to undo another preview.
        if name is None or (name == self._current and not self._previewed):
            return
        self._timer = self.set_timer(self.DEBOUNCE, lambda: self._preview(name))

    def _preview(self, name: str) -> None:
        if self._previewer is not None and self._previewer.preview(self._path, name):
            self._previewed = True

    def _clear_preview(self) -> None:
        if self._timer is not None:
            self._timer.stop()
        if self._previewer is not None and self._previewed:
            self._previewer.preview(self._path, "")

    @on(OptionList.OptionSelected)
    def _selected(self, event: OptionList.OptionSelected) -> None:
        if event.option.id is not None:
            self._choose(event.option.id)

    @on(Input.Submitted, "#scheme-find")
    def _submitted(self, event: Input.Submitted) -> None:
        options = self.query_one(OptionList)
        if options.highlighted is not None and options.option_count:
            name = options.get_option_at_index(options.highlighted).id
            if name is not None:
                self._choose(name)
        elif event.value.strip():
            self._choose(event.value.strip())

    def _choose(self, name: str) -> None:
        self._clear_preview()
        self.dismiss(name)

    def action_cancel(self) -> None:
        self._clear_preview()
        self.dismiss(None)
```
